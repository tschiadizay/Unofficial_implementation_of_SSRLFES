# Unofficial_implementation_of_SSRLFES
## Short description
Repository contains an unofficial implementation of the paper **"Self-supervised representation learning from electroencephalography signals"**[1]. For dataprocessing, **Pillow** [2] was used. The model was tested on **SLEEP-EDFX** [3, 4].
